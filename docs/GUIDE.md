# Seed Library 测试版 使用说明

> 别让好内容在收藏夹吃灰。
>
> Seed Library 是一个 Windows 本地收藏工具：在浏览器里点赞或收藏 X、YouTube、B站、小红书的内容时，自动收进你电脑上的资料库；可以打标签、分主题、写笔记，并把视频下载到本地离线看。所有资料都保存在你自己的电脑上。
>
> **遇到任何安装或使用问题，可以把这份文件整个发给你的 AI 助手（ChatGPT、Claude、Kimi 等），让它一步步带你操作。** 文末有一段专门写给 AI 助手的说明。

当前版本：见安装包文件名（例如 `Seed-Library-0.3.0-Setup.exe` 即 0.3.0），也可在客户端右上角 **?** 使用指南的标题下看到。

---

## 1. 系统要求

- Windows 10 / 11（64 位）。
- Microsoft Edge WebView2 Runtime：Windows 11 自带；Windows 10 大多已随 Edge 安装。如果安装器提示缺失，请到微软官网搜索 “WebView2 Runtime” 下载 “Evergreen Bootstrapper” 安装后再运行本安装包。
- Chrome 或 Edge 浏览器（用于安装收藏插件）。
- 磁盘空间：程序约 450 MB；下载的视频另算，建议资料目录所在磁盘预留几 GB。

## 2. 安装

1. （可选）校验安装包：在安装包所在文件夹打开 PowerShell，运行
   `Get-FileHash .\Seed-Library-0.3.0-Setup.exe -Algorithm SHA256`
   把结果和发布时附带的 `.sha256.txt` 对比，一致说明文件完整、没有被改动。
2. 双击运行安装包。**Windows 可能提示“Windows 已保护你的电脑”**：测试版还没有代码签名，这是正常现象。点 **“更多信息” → “仍要运行”**。
3. 选择程序安装位置。默认 `D:\Apps\seed-preview`，没有 D 盘时会改用你用户目录下的 Programs 文件夹。不需要管理员权限，选一个你自己能写入的文件夹即可。
4. 选择是否创建桌面快捷方式、是否开机启动（开机启动之后也能在 设置 → 外观 → 启动 中修改）。
5. 安装完成后勾选 “打开 Seed Library，选择资料位置”。

## 3. 首次启动：选择资料目录

首次打开会让你选择 **资料目录**：收藏记录、笔记、下载的视频、备份都会存在这里。

- 默认 `D:\PersonalLibrary-Tauri-Preview`，可以换成任意空文件夹。
- 不能放在程序目录里面。
- 选好后点 “确认位置并开始”。以后可以在 设置 → 存储 查看位置。

## 4. 安装浏览器插件（Chrome / Edge）

插件还没有上架应用商店，需要用“开发者模式”加载，只需做一次：

1. 在浏览器地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开页面右上角（Edge 在左侧栏）的 **“开发者模式”**。
3. 点 **“加载已解压的扩展程序”**，选择文件夹：`程序目录\app\browser-extension`
   - 默认安装位置下就是 `D:\Apps\seed-preview\app\browser-extension`。
   - 客户端右上角 **?** → 快速开始 里可以直接复制这个路径。
4. 点浏览器右上角的拼图图标，把 **Seed Library** 固定到工具栏。
5. Chrome 可能每次启动时提示“请停用开发者模式扩展程序”，点关闭即可，不影响使用。

## 5. 连接客户端

1. 打开 Seed Library 客户端，点右上角 **?** → 快速开始 → **复制连接码**（或 设置 → 连接 → 复制连接码）。
2. 点浏览器工具栏上的 Seed Library 图标 → 底部 **“连接设置”**。
3. 把连接码粘贴进去，点 **“连接资料库”**。

连接成功后，插件弹窗右上角会显示 “无待提交”。

## 6. 日常使用

- **自动收录**：在 X、YouTube、B站、小红书上照常点赞或收藏，就会自动收进资料库。插件弹窗里的 “自动收录” 可以选择哪些动作生效。插件不会替你点赞或收藏。
- **手动收藏**：任意网页点插件里的 “收藏此页”；X 和 YouTube 需要在具体帖子或视频页面收藏。也可以在客户端右上角 “＋ 链接” 直接粘贴链接。
- **客户端没开也没关系**：插件会先把收藏暂存在浏览器里，客户端启动后自动提交。
- **下载视频**：鼠标移到卡片上点下载按钮；或点 “选择” 多选后 “下载所选视频”（会先估算体积）。进度在右上角下载图标里。
- **整理**：嫩芽按钮 = 稍后研究；“＋ 标签” 或把卡片拖到左侧标签上；“主题” 用来把一组相关资料放在一起写研究说明。
- **预览**：卡片上的预览按钮（或选中后按空格）在右侧打开预览面板，可以播放、改标签、写笔记；单击卡片进入完整阅读页。
- 客户端右上角 **?** 是完整的使用指南和快捷键列表。

关闭窗口后程序会留在系统托盘（任务栏右下角）；右键托盘图标可以打开、重启或退出。

## 7. 更新到新版本

1. 右键托盘图标 → **退出**（一定要先完全退出旧版本）。
2. 运行新的安装包，安装到**同一个程序目录**。资料目录不受影响。
3. 打开 `chrome://extensions`，在 Seed Library 插件上点 **“重新加载”** 图标（圆形箭头）。已经打开的网页会自动补上新脚本；如有异常刷新一下网页即可。

## 8. 卸载

在 Windows 设置 → 应用 中卸载 “Seed Library 测试版”，或运行程序目录里的 `Uninstall.exe`。
卸载**不会删除资料目录**。如果确定不再需要，再手动删除资料目录。浏览器插件在 `chrome://extensions` 里单独移除。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 安装时提示 “Windows 已保护你的电脑” | 测试版未签名。点 “更多信息” → “仍要运行”。 |
| 提示缺少 WebView2 | 安装微软官方的 WebView2 Runtime 后重试。 |
| 插件显示 “采集脚本未生效” | 刷新那个网页。 |
| 插件一直显示 “待提交 N” | 确认客户端在运行（托盘里有图标）。插件弹窗会逐条显示没提交的原因；如果原因是“服务拒绝（HTTP 400）”之类，说明这条链接本身不能收藏，可以点 “移除”。 |
| 插件显示连接失败 / 401 | 连接码失效或连到了别的客户端。重新复制连接码，在插件 “连接设置” 里再连接一次。 |
| 视频下载失败 | 平台改版时下载组件可能暂时失效。截图失败提示反馈给我们；收藏记录不会丢失。 |
| 找不到下载的文件 | 在客户端里打开那条资料，点 “打开文件夹”；或在 设置 → 存储 查看资料目录。 |
| 想备份 | 设置 → 导出与备份；完整备份请连同资料目录里的 `data` 文件夹一起复制。 |

## 10. 这个测试版的已知限制

- 没有代码签名，首次运行会被 SmartScreen 提示。
- 插件未上架商店，需要开发者模式加载。
- 暂不支持从旧版本或 Electron 版迁移已有资料。
- 下载组件（yt-dlp）打包在安装包内，暂时没有自动更新；平台改版后可能需要等新版本。
- 不包含 AI 助手和转录功能。

你正在帮助一位用户安装或使用 Seed Library 测试版。关键事实：

- 这是 Windows 桌面客户端（Tauri 外壳 + 内置 Node.js 本地服务），本地服务监听 `http://127.0.0.1:48739`，只在本机访问。
- 默认程序目录 `D:\Apps\seed-preview`（没有 D 盘时为 `%LOCALAPPDATA%\Programs` 下）；浏览器插件目录是 `程序目录\app\browser-extension`，用 Chrome/Edge 的“开发者模式 → 加载已解压的扩展程序”加载。
- 默认资料目录 `D:\PersonalLibrary-Tauri-Preview`，用户可在首次启动时更改；客户端日志在 `资料目录\runtime\tauri-service.log`。
- 插件与客户端通过“连接码”配对：客户端 设置 → 连接（或右上角 ? → 快速开始）复制，插件弹窗底部“连接设置”粘贴。
- 插件弹窗显示“待提交”表示收藏暂存在浏览器里还没被客户端接收；每条会显示原因。HTTP 400 类原因表示该链接不可收藏，可以移除；连接失败类原因需要确认客户端在运行并重新配对。
- 更新前必须从托盘右键“退出”旧版本；卸载不会删除资料目录。
- 请不要建议用户关闭 Windows 安全功能或 SmartScreen；只需在提示框中点“更多信息 → 仍要运行”。
- 请不要让用户手动编辑资料目录里的数据库文件。
